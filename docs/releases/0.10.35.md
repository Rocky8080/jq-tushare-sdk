# jq-tushare-sdk 0.10.35 修复说明

日期：2026-10-10。该版本包含 0.10.34 的财务与执行一致性修复，以及 0.10.35 的零交易、预告契约和分红权益修复。

## 版本标识

`VERSION`、`pyproject.toml` 的项目版本和 `jq_tushare_sdk.__version__` 均为 `0.10.35`。修改清单见仓库根目录 `CHANGELOG.md` 的 0.10.34/0.10.35 条目。本次发布整理保留已经验证的运行代码。

## 修复内容

- 分离财务请求日期、报表季度与回放可见时点；拒绝未来 EOD 读数和含糊的 date/statDate 组合。
- 保持必需财务表的交集及空表结构，分开年累计、单季度和有符号 TTM；缺失估值带来源状态，不静默补零。
- 明确 `cached_snapshot`、`research_reconstructed`、`strict_pit` 模式，保留实际采集时间和追加式财报版本记录。
- 将 finance 接口导出到实际策略命名空间，网页运行设置完整传递财务模式。
- 通过 `JQTS_DATA_REQUIREMENTS` 在加载策略前核验预告接口能力和完整的公告日期窗口，包括真实成功响应支持的空日。
- 允许大型纯标量股票代码池进入策略运行状态，继续拒绝不安全的 Redis 引用及超出容器、引用或深度边界的对象。
- 修正模拟滑点、科创板委托数量、股票 T+1、原生日期对象及按完整交易日历调度。
- 企业行动读取统一缓存与年度分片，去重并采用税前现金分红及总送转比例；保存登记日权益、FIFO 税批次与 `artifacts/corporate_action_ledger.json`。

## 验证

0.10.35 修复代码的 SDK 回归已通过 440 项测试及 24 个子测试。策略 V6.5.25 的季度与半年真实缓存研究回测完成，分别通过 47、48 项独立核验，覆盖资金、持仓、费用、T+1、分红、复权及查询时点。半年运行覆盖 125 个交易日、919 个订单和 897 笔模拟成交，数据中止为零。

这些回放证据保存在关联 Join 项目的 Git ignored `jq_tushare_backtests/` 下，不随 SDK 分发，不证明聚宽原生或实盘等价。

## 未支持与未验证能力

- 原生 `STK_FIN_FORCAST` 字段映射仍未认证；独立 `TUSHARE_FORECAST` 研究接口不能冒充聚宽原生数据。
- 当前缓存迁移无法补回丢失的历史财报版本，严格 PIT 和分钟撮合一致性仍需独立证据。
- 已持仓的延期现金/股份分配、未认证碎股分配、缺少认证税基的红股事件明确报错，不能按完整企业行动支持宣传。
- 现金股息采用 20% 预扣与 FIFO 卖出持有期退差的研究模型，实盘扣税时间和资本公积税务来源未认证。
- 关联策略在 2026-05-07、05-08 的固定自然日窗口触发默认值，导致短期相对收益筛选失效。逐码 SQL 核验没有源行情缺行，未发现 SDK 数据缺失；该策略规则尚未修订，收益影响尚未量化。

发布状态为已实现且有回归和研究回放证据的修复版本，不表示所有聚宽兼容能力或策略规则均已完成。
